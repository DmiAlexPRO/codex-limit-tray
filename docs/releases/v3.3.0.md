Codex Limit Tray now explains how to keep its icon visible.

- **Windows:** Open **Appearance → Open taskbar settings** to get to the system controls. You can also drag the icon out of the hidden icons menu (↑).
- **macOS:** Appearance explains where to find the icon and which system setting to check if it is hidden on macOS 26 or later.

## Downloads

- **Windows x64 installer:** installs for the current user.
- **Windows x64 ZIP:** runs without installation.
- **macOS ZIP:** experimental, with manual installation and updates. Choose Apple Silicon or Intel.

The Windows installer has no Authenticode publisher signature; macOS bundles are not notarized.

**По-русски:** в разделе «Оформление» появились подсказки о том, как оставить значок приложения на виду. В Windows там же можно открыть параметры панели задач.
