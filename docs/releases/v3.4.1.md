The tray menu now has a single **Quit Codex Limit Tray** entry. **Open window** shows the main window, **Refresh limits** fetches new quota data, **Show widget** opens the floating widget, and **Settings** opens the app settings.

The macOS packages for Apple Silicon and Intel target macOS 13 or later.

**По-русски:** в меню значка теперь один пункт **«Выйти из Codex Limit Tray»**. Пункты **«Открыть окно»**, **«Обновить лимиты»**, **«Показать виджет»** и **«Настройки»** открывают нужный экран или выполняют указанное действие. Сборки для Intel и Apple Silicon рассчитаны на macOS 13 и новее.

The Windows installer has no Authenticode publisher signature; macOS bundles are not notarized.
