See and use earned Codex limit resets from the dashboard.

- The reset count and expiration dates appear when Codex provides them. The list scrolls after five entries without resizing the window.
- Select **Reset…** and confirm to spend one reset. The app then refreshes your limits.

**По-русски:** под лимитами отображаются доступные сбросы и их сроки действия. Список из более чем пяти записей прокручивается внутри блока. Кнопка **«Сбросить…»** запрашивает подтверждение, затем приложение обновляет лимиты.

The Windows installer has no Authenticode publisher signature; macOS bundles are not notarized.
