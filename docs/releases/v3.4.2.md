Change the language in **Appearance → Language**. The window and the tray menu update immediately; no restart is needed. Your choice is saved.

If an older version shows HTTP 403 while checking for updates and GitHub's request limit has been reached, wait for the limit to reset or download the installer from this release page.

**По-русски:** выберите язык в разделе **Оформление → Язык**. Окно и меню в трее обновятся сразу, без перезапуска. Если старая версия не может проверить обновления из-за лимита GitHub API, скачайте установщик с этой страницы релиза.
