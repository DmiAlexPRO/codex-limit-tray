Change the language in **Appearance → Language**. The window and the tray menu update immediately; no restart is needed. Your choice is saved.

If GitHub rate-limits an update check, the app shows when you can try again and offers **Open release page** for a manual download. If an older version shows HTTP 403 for the same reason, you can download the installer directly from this page.

**По-русски:** выберите язык в разделе **Оформление → Язык**. Окно и меню в трее обновятся сразу, без перезапуска. При лимите GitHub приложение покажет, когда повторить проверку, и предложит **«Открыть страницу релиза»**. Если старая версия выдаёт HTTP 403 из-за лимита, скачайте установщик прямо с этой страницы.
