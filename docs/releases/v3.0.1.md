First release after the repository history cleanup.

This release updates the Go toolchain and dependencies. It keeps the version above 3.0.0 so existing Windows installations can receive the signed update without losing settings.

Choose `CodexLimitTray-windows-x64-Setup.exe` for a per-user installation, or the Windows ZIP to run without installing. macOS remains experimental, with manual installation and updates. Windows builds do not have an Authenticode publisher signature; macOS bundles are not notarized.

По-русски: это первый релиз после очистки истории репозитория. Обновлены Go и зависимости. Для установленной версии Windows работает подписанное автообновление с 3.0.0; настройки сохраняются. В macOS установка и обновление остаются ручными.
