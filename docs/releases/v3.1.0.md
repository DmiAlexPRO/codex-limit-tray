Codex Limit Tray now has **20 interface languages**. On a fresh installation the app uses a supported system language, or English if none matches. To change it, open the gear → **Appearance → Language**, choose a language, and restart the app. Upgrades keep your selection and other settings.

## Languages

English, Simplified Chinese, Hindi, Spanish, Modern Standard Arabic, French, Bengali, Portuguese, Indonesian, Urdu, Russian, German, Japanese, Nigerian Pidgin, Egyptian Arabic, Marathi, Vietnamese, Telugu, Swahili, and Hausa. The list follows total first- and second-language speakers in the [2026 Ethnologue ranking](https://en.wikipedia.org/wiki/List_of_languages_by_total_number_of_speakers#Ethnologue_(2026)).

GitHub release notes retain their original language. OS and toolkit controls may follow the system language; technical diagnostics can be in English.

## Downloads

- **Windows x64 installer:** installs for the current user. The installer wizard detects the system language from the translations bundled with Inno Setup; the app supports all 20 languages independently.
- **Windows x64 ZIP:** run without installing. The app detects the language on first launch if no preference exists.
- **macOS ZIP:** experimental, with manual installation and updates. Select the archive for your processor.

The Windows installer has no Authenticode publisher signature; macOS bundles are not notarized.
