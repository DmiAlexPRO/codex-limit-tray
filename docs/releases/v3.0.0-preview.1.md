See how much of your five-hour and weekly Codex allowances remains, and when each resets, without opening another window. Uses your locally signed-in Codex; no extra account, API key or telemetry. The app interface is in Russian.

Windows x64: download CodexLimitTray-windows-x64-Setup.exe for a per-user install. The installed edition verifies updates and applies them at startup by default. Prefer manual updates? Turn off «Автоматически устанавливать обновления при запуске» in Settings → Updates. The portable ZIP never installs anything without a click.

macOS: choose arm64 for Apple Silicon or x86_64 for Intel. These are experimental, unsigned, non-notarized builds; installation and updates are manual.

Windows SmartScreen may warn on first launch: the installer has no Authenticode publisher signature. Its companion .sig authenticates in-app updates, not the initial download.

По-русски: остаток лимитов и время сброса видны в трее и компактном виджете. Для Windows выбирайте Setup; ZIP — для запуска без установки. Заметки и настройка автообновлений находятся в «Настройки → Обновления».
