3.0.0 · Stable for Windows x64

Choose CodexLimitTray-windows-x64-Setup.exe for a per-user installation, or CodexLimitTray-windows-x64.zip to run without installing. The app shows the remaining five-hour and weekly quotas reported by your local, signed-in Codex.

Moving from preview? Your preferences carry over. Installed Windows copies check GitHub on startup by default, verify the new installer and restart in the tray after updating. From 3.0.0 onward, the stable edition follows stable releases only. Turn off automatic installation in Настройки → Обновления to check manually instead. Portable copies never check or install automatically.

The built-in updater verifies an Ed25519 signature before launching the installer. The first download does not have a Windows Authenticode publisher signature, so SmartScreen may warn.

macOS remains experimental: if a ZIP is available for your architecture, install and replace the app manually. In-app checks show release notes only. Mac builds are unsigned and not notarized.

В macOS установка и обновление остаются ручными.
