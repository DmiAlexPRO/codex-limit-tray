Codex Limit Tray now supports **27 interface languages**. This release adds Belarusian, Kazakh, Ukrainian, Polish, Italian, Turkish, Kyrgyz and Armenian.

To change the language, open the gear → **Appearance → Language** and restart the app. A fresh installation uses a supported system language or falls back to English. Upgrading keeps your existing choice. The dashboard buttons now adjust to longer translated labels.

## Downloads

- **Windows x64 installer:** installs for the current user. The setup wizard also adds Armenian, Italian, Polish, Turkish and Ukrainian. All eight new languages are available in the app.
- **Windows x64 ZIP:** runs without installation.
- **macOS ZIP:** experimental, with manual installation and updates. Choose the archive for Apple Silicon or Intel.

The Windows installer has no Authenticode publisher signature; macOS bundles are not notarized.

**По-русски:** добавили белорусский, казахский, украинский, польский, итальянский, турецкий, кыргызский и армянский. Всего в приложении 27 языков. Чтобы сменить язык, откройте **Оформление → Язык** и перезапустите приложение. При обновлении выбранный язык сохраняется.
