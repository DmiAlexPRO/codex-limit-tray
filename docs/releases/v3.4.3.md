Codex Limit Tray now supports **29 interface languages**. Choose **Čeština** or **한국어** in **Appearance → Language**. The window and tray menu update immediately, and your choice is saved.

The Windows installer is also available in Czech and Korean. On first launch the app still uses a supported system language or falls back to English. Updating preserves your saved language.

Earned limit reset messages are now translated in all supported languages.

The [project website](https://dmialexpro.github.io/codex-limit-tray/) is available in 11 languages. It opens in English by default; use the language menu to switch.

**Česky:** Češtinu zapnete v nabídce **Vzhled → Jazyk**. Změna se projeví ihned.

**한국어:** **모양 → 언어**에서 한국어를 선택하면 다시 시작하지 않아도 바로 적용됩니다.
