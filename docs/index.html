Codex limits in the Windows system tray

See what’s left of your five-hour and weekly Codex limits and when they reset. Keep the indicator next to the clock or open a small widget that stays on top.

Setup

How to show Codex limits in the tray

  1. Sign in to Codex. Use Codex Desktop or run codex login. Codex Limit Tray doesn’t need a separate account or API key.
  2. Run the Windows installer. It installs for your Windows account without admin rights. The installer is unsigned, so Windows SmartScreen may show a warning. Download it only from this project’s GitHub Releases.
  3. Open Codex Limit Tray. Close its window to leave it running in the tray. Click the icon to see the remaining amounts and reset times.

Can’t see the tray icon?

Open the hidden-icons menu (↑) and drag the app icon next to the clock. To show it after signing in to Windows, turn on Appearance → Start at login in the app.

Codex Limit Tray is independent and not affiliated with OpenAI. It shows Codex subscription limits, not general ChatGPT limits or API spending.
