# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, religion or sexual identity and orientation.

## Expected behavior

- Be respectful, constructive and open to differing viewpoints.
- Give and accept technical feedback without personal attacks.
- Focus on what is best for users and the project.
- Show empathy toward other community members.

Unacceptable behavior includes harassment, sexualized attention, trolling, insults, publishing private information and conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit or reject comments, commits, code, issues and other contributions that violate this Code of Conduct, and may temporarily or permanently restrict participation.

Report conduct concerns through the repository owner's listed GitHub contact. Security-related reports should use private vulnerability reporting as described in `SECURITY.md`. Maintainers will respect the reporter's privacy as far as reasonably possible.

## Scope

This Code of Conduct applies within project spaces and when an individual officially represents the project in public spaces.
